# 修改 GitHub Pages 部署方案

- 备份了原始工作流文件：`.github/workflows/deploy.pages-backup.yml`
- 将 `.github/workflows/deploy.yml` 从 GitHub 官方 Pages artifact 部署方式改为：
  - 在 `main` 分支触发
  - 使用 `actions/setup-node@v4` 固定 Node 版本为 `24.9.0`
  - 使用 `pnpm/action-setup@v4` 固定 pnpm 版本为 `9.14.4`
  - 执行 `pnpm install --frozen-lockfile`
  - 执行 `pnpm build`
  - 将构建产物 `./dist` 发布到 `gh-pages` 分支
- 这样后续每次推送 `main` 后，构建结果会提交到 `gh-pages`，而不是使用 GitHub Pages 的 artifact deployment 模式。
